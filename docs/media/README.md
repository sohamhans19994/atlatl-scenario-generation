# Demo media

The public documentation uses these exported research visuals:

- `hero-animation.webp`: the source-rendered hero showing requirements,
  design, map instantiation, replay, evaluation, and refinement. It is exported
  directly from the HTML timeline as a true-color animated WebP so typography
  and map geometry remain sharp when rendered by GitHub;
- `actual-evolution.gif`: animated parent-to-RCC relationships reconstructed
  from a stored evolution graph, followed by a successful real replay;
- `actual-evolution-graph.webp`: static, accessible version of that recorded
  search graph;
- `mind-evolution-adaptation.svg`: original diagram showing how Google
  DeepMind's Mind Evolution method is adapted to scenario generation;
- `narrow-channel-demo.gif`: a real replay of the generated narrow-channel
  scenario;
- `scenario-library.webp`: the six reference scenarios from the research
  presentation;
- `research-pipeline.svg`: an original redraw of the project pipeline.

The simulator footage is approved for public display. AtlAtl source and browser
renderer code are not included in this repository. Full-length recordings
should be hosted as release assets instead of being added to normal Git history.
The hero is an explanatory animation; `narrow-channel-demo.gif` and the replay
at the end of `actual-evolution.gif` contain the recorded simulator footage.
